# Changelog

| Version | Date       | Description                                                                                                   |
|---------|------------|---------------------------------------------------------------------------------------------------------------|
| 2.4.0   | 2026-08-03 | Robustness and maintainability pass. Per-entity error isolation in the state handler so one misconfigured binding no longer stops all updates; null-safe panel/sidebar detection that degrades instead of crashing when Home Assistant restructures its frontend; replaced `eval` in entity templates with a scoped `new Function` that also fails gracefully. New `debug` option silences ~20 informational console logs by default (warnings/errors still show). Editor now exposes `max_pixel_ratio`, `model_cache`, `draco_decoder_path`, and `debug`. Loading/error messages are localized (en/de/es/ru/nb). Added an ESLint rule to reject assignment-in-condition, plus a committed browser test harness and Playwright smoke test wired into CI. |
| 2.3.1   | 2026-07-31 | Fixed light color_mode checks that used assignment instead of comparison (corrupted the shared state object and forced a re-render on every light update) and array reference comparisons that never matched. Replaced the 250ms z-index polling loop with IntersectionObserver + visibilitychange for zero idle CPU cost (note: animations no longer pause behind open dialogs, only when offscreen/backgrounded). Added WebGL context-loss recovery so the canvas redraws instead of staying blank after mobile browsers evict the GL context. |
| 2.3.0   | 2026-07-31 | Mobile load-time improvements: support for Draco and meshopt compressed .glb models (5-10x smaller downloads, new `draco_decoder_path` option), on-device model caching with background revalidation for near-instant repeat loads (new `model_cache` option, HTTPS only), rendering pixel-ratio cap of 2 on high-DPR phones (new `max_pixel_ratio` option), and `high-performance` WebGL context hint. |
| 2.2.0   | 2026-07-30 | Added spin-up / coast-down easing to the `rotate` binding via a new `ramp` option (default 1.5s, set 0 for instant). Rotating objects now accelerate and slow down naturally instead of snapping between speeds. |
| 2.1.2   | 2026-07-28 | Bumped GitHub Actions (checkout, setup-node) to v5 to clear Node 20 deprecation warnings. |
| 2.1.1   | 2026-07-28 | Restored Norwegian (Bokmål) language support with typo fix and added missing show_error string. Pinned CI workflows to Node 18 to fix tslib incompatibility with Node 24. Skipped lint step in release builds. |
| 2.1.0   | 2026-07-28 | Added language support for German, Spanish, and Russian. Removed Norwegian locale from original fork.         |
| 2.0.0   | 2026-07-28 | Full rebrand from floor3d-card to hass-3d-floorplan. New custom element names, authorship, HACS identity. Removed stale dist artifacts and tsconfig schema blob. Updated CI workflows to actions v4. |
| 1.5.3   | 2023-04-01 | Forked from [adizanni/floor3d-card](https://github.com/adizanni/floor3d-card). Fixed editMode in 2023.4.      |
